# 内置插件 / Built-in plugins

[返回项目 README / Back to project README](../../../README.md)

内置插件随主程序发行，无需上传 ZIP 或重新构建前端。不同插件可提供各自的连接方式和硬件能力。当前物理硬件写入被禁用。

Built-in plugins ship with the application. No ZIP upload or front-end rebuild is needed. Each plugin defines its own transports and capabilities. Physical hardware writes are currently disabled.

| 插件 / Plugin | 连接方式 / Transports | 状态 / Status |
|---|---|---|
| [Huawei iMana 200](huawei-imana-200.md) | SSH / Local IPMI | 只读安全预览 / Read-only preview |
| Mock | Virtual | 模拟控制 / Simulation |

第三方插件开发 / Third-party development: [Plugin SDK](../../plugin-sdk.md).
